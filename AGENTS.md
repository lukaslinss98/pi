# AGENTS.md — Pi Agent Config Directory

This directory (`~/.config/pi/`) holds the user configuration for the **pi coding agent**. It is **not a source code project** — it is a runtime config directory. Changes here affect how pi behaves globally.

## Directory Structure

```
~/.config/pi/
├── AGENTS.md                    ← this file
├── agent/
│   ├── settings.json            ← Main configuration (provider, model, theme, skills, packages, vim mode, extensions)
│   ├── keybindings.json         ← Custom TUI keybindings
│   ├── ghostty-theme.json       ← Ghostty terminal theme override
│   ├── models-store.json        ← Cached model definitions from providers (auto-managed, large)
│   ├── auth.json                ← Provider API keys and credentials (auto-managed)
│   ├── bin/
│   │   └── fd                   ← Bundled `fd` binary (do not modify)
│   ├── extensions/
│   │   └── vim-mode.ts          ← Custom vim-mode extension written in TypeScript (~400 lines)
│   ├── sessions/                ← Session history logs (*.jsonl) — runtime data, do not edit
│   └── npm/                     ← NPM dependencies for extensions (auto-managed)
└── context-mode/
    ├── content/                  ← Context-mode content database (runtime data, do not touch)
    └── sessions/                 ← Context-mode session files and stats (runtime data, do not touch)
```

## Key Files

### `agent/settings.json`
The primary config file. Must remain valid JSON. Key fields:

| Field | Description |
|---|---|
| `defaultProvider` | LLM provider (e.g., `"openrouter"`) |
| `defaultModel` | Default model ID (e.g., `"deepseek/deepseek-v4-flash"`) |
| `theme` | TUI theme name |
| `defaultThinkingLevel` | `"high"`, `"medium"`, `"low"`, or `"none"` |
| `skills` | Array of paths to skill directories |
| `packages` | Array of package references (`git:...`, `npm:...`) |
| `extensions` | Array of extension references (`+extensions/...`) |
| `vimMode` | Boolean — enables/disables vim keybindings |
| `hideThinkingBlock` | Boolean — hides reasoning output in TUI |

### `agent/extensions/vim-mode.ts`
A TypeScript extension implementing vim-mode in the pi TUI. Uses the `@earendil-works/pi-coding-agent` SDK. Contains:
- Mode switching (`normal` ↔ `insert`)
- Motion commands (`h/j/k/l`, `w/W`, `b/B`, `e/E`, `0`, `^`, `$`, `{`, `}`, `gg`, `G`, `%`, `f/F/t/T`)
- Operators (`d`, `y`, `c`, `x`, `X`, `s`, `S`, `dd`, `yy`, `cc`, `D`, `C`, `Y`, `p`, `P`, `.`)
- Searching (`/`, `?`, `n`, `N`, `*`, `#`)
- Visual mode (`v`, `V`, `d`, `y`, `c`)
- Register support, undo history, marks, scroll, status bar indicator
- `gi` (go to last insert position), `ZZ`/`ZQ` (save/quit semantics)

### `agent/keybindings.json`
Custom keybindings for the TUI. Currently used to override `ctrl+p`/`ctrl+n` for select navigation and disable model cycling. Reference: `docs/keybindings.md`.

### `agent/ghostty-theme.json`
Ghostty terminal theme configuration. Contains a single `theme` field.

## Conventions

1. **Always validate JSON** after editing `settings.json`, `keybindings.json`, or `ghostty-theme.json`. Use `jq .` to check.
2. **Never modify** runtime/generated files:
   - `agent/models-store.json` — auto-generated by pi
   - `agent/auth.json` — manages API keys, auto-managed
   - `agent/bin/fd` — bundled binary, updated by pi
   - `agent/sessions/` — raw session logs
   - `agent/npm/` — extension dependencies, auto-managed
   - `context-mode/` — fully auto-managed databases and stats
3. **Extension code** lives in `agent/extensions/`. The `vim-mode.ts` extension uses the pi SDK (`@earendil-works/pi-coding-agent`). Extension references in `settings.json` use the `+extensions/` prefix.
4. **Skills** are loaded from external directories (referenced in `settings.json` via `skills` array). The skills directory `~/dev/agent-skills/` is the primary source.
5. **Packages** are references to external resources. When adding a new package in `settings.json`, ensure the reference format is correct (`git:github.com/...`, `npm:...`, etc.).
6. **Session history** files (`*.jsonl`) are append-only logs. They can be read for debugging but never edited.

## Validation

Before committing changes, run:

```bash
# Validate JSON files
jq . agent/settings.json > /dev/null
jq . agent/keybindings.json > /dev/null
jq . agent/ghostty-theme.json > /dev/null

# Type-check extension
cd agent/extensions && npx tsc --noEmit vim-mode.ts
```

## Environment

Pi reads `PI_CODING_AGENT_DIR` (defaults to `~/.pi/agent` on Linux, `~/.config/pi/agent` on macOS). The config directory is `~/.config/pi/` on macOS. All paths in this file are relative to `~/.config/pi/`.
